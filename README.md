Novel Hub 
A web-based reading platform where users can browse and read books and stories online.
About
Novel Hub is a frontend reading platform built with HTML, CSS, and JavaScript. It provides a clean and user-friendly interface for discovering and reading stories.
Features

Browse and read books and stories
Clean, responsive UI for comfortable reading
Lightweight and fast — no backend required

Tech Stack
HTML
CSS
JavaScript

How to Run
Clone the repository
git clone https://github.com/yourusername/novel-hub.git

Open index.html in your browser
That's it!
